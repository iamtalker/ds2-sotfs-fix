# DS2 SotFS 수정 도구

다크소울 2 Scholar of the First Sin(PC)의 두 가지 불편을 고치는 도구입니다.

1. **시작할 때 느린 입력 문제 ("더블클릭 무효화" 옵션)**
   게임을 켤 때마다 옵션을 껐다 켜야 빨라지던 문제를 고칩니다.
2. **키 합치기 (다크소울 3 방식 조작)**
   - 스페이스바: 달리기/구르기, 대시 중에 뗐다가 바로 다시 누르면 점프
   - Q: 락온 + 메뉴 뒤로가기를 한 키로

설치 프로그램에서 두 기능을 따로 고를 수 있고, 게임 폴더는 직접 선택합니다.

## 사용법

1. `DS2_Fix_Installer.exe`를 실행합니다.
2. `DarkSoulsII.exe`가 있는 폴더를 고르고, 설치할 기능을 체크한 뒤 **설치**를 누릅니다.
3. 앞으로 게임은 폴더에 생긴 **`launch_ds2.exe`** 로 실행합니다. (`DarkSoulsII.exe`를 직접 실행하면 적용되지 않습니다.)

   **고급 옵션 "DarkSoulsII.exe 를 실행기로 대체"** (기본 꺼짐)를 켜면 원래 exe가 `DarkSoulsII_original.exe`로 이름이 바뀌고
   실행기가 `DarkSoulsII.exe` 이름을 씁니다. 그러면 평소처럼 `DarkSoulsII.exe`를 실행해도 적용됩니다.
   이름을 바꾼 뒤에도 게임이 실행되는지는 환경마다 다를 수 있으니, 문제가 생기면 **제거(원복)** 로 되돌리세요.
4. 키 합치기를 설치했다면 DS2 키 설정에서 아래처럼 지정합니다. 설치 화면의 입력 칸 4개에서 다른 키로 바꿀 수 있고
   (게임에 지정한 키와 같아야 합니다), 이미 설치된 설정이 있으면 그 값이 칸에 먼저 채워집니다. 설치 후에는 `ds2_keys.ini`에서도 바꿀 수 있습니다.
   DS2는 키 설정이 세이브 파일에 저장되므로, 세이브를 바꾸면 키 설정도 같이 바뀝니다.

   | DS2 동작 | 지정할 키 |
   |---|---|
   | 달리기/구르기 | `7` |
   | 점프 | `8` |
   | 락온 | `9` |
   | 메뉴 뒤로가기 | `0` |

   DS2에서는 이 기능이 켜져 있는 동안 진짜 스페이스바와 Q를 받지 못합니다.

제거는 설치 프로그램의 **제거(원복)** 버튼으로 합니다. 설치 때 만든 원본 백업(`DarkSoulsII.exe.bak`)으로 되돌립니다.

## 주의

- **온라인 플레이에서는 사용하지 마세요.** 게임 파일과 실행 중인 메모리를 수정하므로 계정 제재 위험이 있을 수 있습니다.
- 더블클릭 수정(exe 패치)은 **분석한 빌드에만** 적용됩니다. 설치 프로그램이 해시로 검사하고, 다른 버전은 건너뜁니다. 키 합치기는 빌드와 무관합니다.
- 키 입력을 가로채고 다른 프로세스의 메모리를 쓰기 때문에 백신이 오탐할 수 있습니다. 서명이 없는 파일입니다.
- **검증 범위**: 아래 "지원하는 exe 빌드" 한 가지, Windows 11 한 대에서 설치 → 실행 → 제거(대체 모드 포함)를 직접 확인했습니다.
  정식 스팀판, 다른 Windows 버전, 온라인 환경에서는 확인하지 않았습니다.

## 지원하는 exe 빌드

더블클릭 수정(exe 패치와 메모리 고정)은 아래 조건과 정확히 일치하는 `DarkSoulsII.exe`에만 적용됩니다. 설치 프로그램이 해시로 검사하고, 다르면 건너뜁니다.

| 항목 | 값 |
|---|---|
| 크기 | 31,605,096 바이트 |
| SHA-256 | `d83922bb1a27b2860e3e2f593333ec2d1db2bddf2a51eb39d141ecbab0652334` |
| PE 타임스탬프 | `0x5535…` (2015-04-20, 십진수 1429527574) |

이 빌드는 스팀 정식판 최신 빌드와 다릅니다. 기존에 알려진 수정 도구(2022-09-16 빌드의 주소를 쓰는 것)가 이 빌드에서 동작하지 않은 이유이기도 합니다.
키 합치기는 빌드와 무관하게 어떤 DS2에서든 쓸 수 있습니다.

## 알려진 한계와 요령

- 대시하다가 스페이스바를 떼면 달리기키를 `rejump_window`(기본 200ms) 동안 유지하므로, 대시를 멈출 때 그만큼 더 달립니다. 점프가 어려우면 값을 늘리고, 멈춤이 느리면 줄이세요.
- DS2는 모든 동작에 키를 지정해야 하고 비워 둘 수도 없습니다. 안 쓰는 동작에는 겹치지 않는 아무 키(숫자패드 숫자 등)를 채워 두면 우리가 쓰는 키를 비울 수 있습니다. 키 지정 화면에서 F1~F12는 고를 수 없었습니다.
- 이 기능이 켜져 있는 동안은 게임이 진짜 스페이스바와 Q를 받지 못합니다.
- 설치 프로그램은 DS2의 키 설정을 대신 지정해 주지 못합니다. 키 설정은 암호화된 세이브 파일 안에 있습니다.

## 설정 (`ds2_keys.ini`)

시간 값은 밀리초입니다. 값을 바꾸면 게임을 껐다가 `launch_ds2.exe`로 다시 실행하세요.

| 항목 | 의미 |
|---|---|
| `sprint_hold` | 이 시간 이상 누르고 있어야 "대시"로 인정 (미만이면 구르기) |
| `rejump_window` | 대시 중에 스페이스바를 뗀 뒤 이 시간 안에 다시 누르면 점프 |
| `jump_delay` / `jump_press` | 점프키를 보내기까지의 지연 / 누르고 있는 시간 |

## 동작 원리

**더블클릭 문제.** 이 빌드에서 옵션 값은 게임 안의 객체(`KatanaMainApp` 전역 → `+0x60` → 역참조 → `+8`)의 `+0x6d` 바이트로 복사됩니다. 설정을 적용하는 함수는 옵션을 바꿀 때만 실행되고 시작 때는 호출되지 않아서, 값이 0인 채로 시작합니다. 두 가지를 합니다.

- exe 패치: 옵션 적용 함수(`0x14019a197`, 파일 오프셋 `0x199597`)가 설정값 대신 항상 1을 쓰게 합니다. (`movzx eax, byte [rcx+0x26]` → `xor eax,eax; inc eax`, 같은 4바이트)
- 실행기: 게임이 시작되면 그 바이트를 1로 맞추고 유지합니다. 메모리 쓰기는 PE 타임스탬프가 일치하는 빌드에서만 합니다.

**키 합치기.** 저수준 키보드 훅으로 스페이스바와 Q를 가로채고, 설정한 키를 `SendInput`(스캔코드)으로 게임에 보냅니다. DS2 창이 맨 앞일 때만 동작하고, 대시 중에 스페이스바를 떼면 달리기키를 `rejump_window` 동안 유지해서 다시 눌렀을 때 끊김 없이 점프키만 보냅니다.

## 개발 메모

- **효과가 없던 시도**: 게임 윈도우 클래스의 `CS_DBLCLKS`(스타일 `0x0B` → `0x03`)를 제거해 `WM_LBUTTONDBLCLK`을 막아 봤지만 증상이 그대로였습니다. "더블클릭 무효화" 옵션은 마우스 더블클릭 메시지가 아니라 위의 `+0x6d` 바이트와 연결되어 있습니다.
- **이 바이트를 읽는 코드는 찾지 못했습니다.** 정적 스캔에서는 잡히지 않았고, 아래 이유로 동적 추적도 중단했습니다. 그래서 이 값이 정확히 무엇을 바꾸는지(체감상 무기 속도/입력 처리)는 모릅니다. 쓰는 쪽을 알고 싶다면 이 바이트를 읽는 명령을 찾아야 합니다.
- **게임에 디버거를 붙이면 게임이 꺼집니다.** 하드웨어 브레이크포인트로 이 바이트를 감시하려다 두 번 실패했습니다(해제하고 떼어내도 동일). 다시 시도하지 마세요.
- 윈도우 파워셸 5.1은 BOM 없는 UTF-8 스크립트의 한글을 못 읽어서, `build.ps1`은 영어로만 씁니다.
- DS2 키 설정은 세이브 파일(`%APPDATA%\DarkSoulsII\<계정>\DS2SOFS0000.sl2`)에 저장됩니다. 세이브를 치워 보고 확인했습니다.

## 빌드

```powershell
py -3 -m pip install pyinstaller
powershell -ExecutionPolicy Bypass -File build.ps1
```

결과물은 `dist\`에 생깁니다.

## 구성

```
src/launch_ds2.py        실행기 (게임 실행 + 값 고정 + 키 레이어)
src/ds2_keys.py          키 합치기 로직
src/ds2_keys.ini         기본 설정
installer/ds2_installer.py  설치 화면
tests/test_installer.py  설치/제거 로직 시험 (원본 DarkSoulsII.exe 경로를 인자로)
build.ps1                exe 빌드 (dist\DS2_Fix_Installer.exe 하나만 생성)
```

시험은 임시 복사본으로만 하며 원본 exe는 읽기만 합니다.

```powershell
py -3 tests\test_installer.py "<원본 DarkSoulsII.exe 경로>"
```
